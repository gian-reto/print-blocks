# Daily weather forecast template

Use this template for compact daily weather forecast slips, kiosk printouts, morning briefings, event preparation notes, or travel reminders.

It contains:

- a centered forecast header
- location and update metadata rows
- a line chart for temperature across the day
- a bar chart for rain probability by time
- summary rows for high, low, and wind
- a short actionable note

Customize the location, update time, chart values, time labels, and summary rows with the latest forecast. The chart labels are intentionally short so the output stays readable on narrow thermal paper.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
