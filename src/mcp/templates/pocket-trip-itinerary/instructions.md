# Pocket trip itinerary template

Use this template for city trips, business travel, rail journeys, flight connections, family vacations, or a compact companion to digital tickets.

It contains:

- traveler, route, and date metadata
- a prominent booking-reference token
- a timeline of transport, check-in, and reservation events
- hotel and emergency-contact rows
- a QR code linking to maps and live trip details
- a barcode carrying a booking or ticket reference

Customize the traveler, route, dates, reference, schedule, contacts, and scannable payloads. Only use barcode or QR data issued by the relevant provider when the printout must function as a real ticket. You can add an embedded image block for a carrier or destination logo.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
