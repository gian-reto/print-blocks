# Goal or project progress template

Use this template for work projects, learning plans, fitness targets, savings goals, home improvements, or any outcome with measurable progress and milestones.

It contains:

- goal and target-date metadata
- a token emphasizing the next milestone
- overall and milestone progress indicators
- a line chart showing progress over time
- a timeline combining recent achievements with upcoming milestones
- a QR code linking to the complete plan or working material

Customize the goal, target date, next milestone, progress values, weekly trend, timeline, and QR destination. Use consistent units throughout and make upcoming timeline descriptions concrete enough to act on immediately.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
