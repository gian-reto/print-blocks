# Meeting summary and action plan template

Use this template to turn meeting notes, transcripts, calls, or workshops into a compact physical record of what matters next.

It contains:

- meeting topic, date, and attendee metadata
- a short list of agreed decisions
- a timeline of action items labeled by due date
- a progress bar for completed follow-ups
- a QR code linking to the complete notes or transcript

Customize the metadata, decisions, owners, deadlines, progress values, and QR destination. Write each action description as `owner - concrete action` so responsibility remains clear after printing.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
