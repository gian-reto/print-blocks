# Recipe and kitchen prep card template

Use this template for everyday recipes, meal-prep instructions, generated recipes based on available ingredients, or simplified cooking directions.

It contains:

- a prominent recipe title
- a three-column row for servings, preparation time, and cooking time
- a token for the most important temperature or timing setting
- ingredient-and-quantity rows
- numbered preparation steps rendered as a timeline
- a QR code linking to substitutions, nutrition, notes, or the source recipe

Customize the title, serving count, timings, cooking setting, ingredients, method, and QR destination. Keep each method step focused on one action. You can add an embedded image block when a dish photo or preparation diagram would be useful.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
