# Budget and upcoming bills template

Use this template for personal budgets, household finances, club accounts, project allowances, or small-team spending summaries.

It contains:

- period and monthly-budget metadata
- a progress bar showing how much of the budget has been used
- spent and remaining summary rows
- a bar chart comparing spending categories
- a timeline of upcoming bills and payment notes
- a recommendation for the remainder of the period

Customize the currency, period, budget, spending values, categories, bill dates, payment notes, and recommendation. Keep category labels concise and ensure that progress and chart values use the same underlying amounts as the printed totals.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
