# Receipt template

Use this template for receipt-style thermal prints, such as store receipts, order summaries, invoices, pickup slips, or event checkouts.

It contains:

- a centered merchant or organization header
- an order or reference line
- separator lines
- item rows with left and right aligned text
- a bold total row
- a footer message

You can customize the merchant name, order number, line items, prices, total, and footer text. Add more row blocks for additional items, remove rows you do not need, and adjust the separator character if a different visual style is useful.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
