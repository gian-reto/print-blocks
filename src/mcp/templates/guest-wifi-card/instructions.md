# Guest welcome and Wi-Fi card template

Use this template for homes, guest rooms, vacation rentals, offices, workshops, events, or any place where visitors need quick network access and a few practical details.

It contains:

- a prominent venue or property name
- readable network and security details
- a token that emphasizes the Wi-Fi password
- a standard Wi-Fi QR payload for scan-to-connect access
- contact and check-out information
- a short welcome message

Customize the property name, SSID, security type, password, QR payload, contact details, and stay information. Keep the visible credentials synchronized with the QR content. Escape special QR payload characters correctly when the SSID or password contains `;`, `,`, `:`, `\`, or quotation marks.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
