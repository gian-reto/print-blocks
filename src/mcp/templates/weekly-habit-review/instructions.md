# Weekly habit and wellness review template

Use this template for habit coaching, wellness reviews, study routines, medication adherence, household routines, or any recurring activity tracked over time.

It contains:

- period and habit-count metadata
- a heatmap of total daily completions across four chronological weeks
- completion-rate and best-streak rows
- step-style progress for the current week's available completions
- a bar chart comparing individual habit totals
- one specific focus for the following week

Customize the tracked period, number of habits, heatmap values, summary statistics, progress values, chart labels, and recommendation. The heatmap rows run from oldest to newest because heatmap rows do not have their own labels.

This template is only a starting point. You may ignore it and submit any custom print request that matches the print schema.
